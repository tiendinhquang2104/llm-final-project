# R15 external artifacts

This directory stores metadata only. Obtain the required files from an
authorized external `task3-artifacts/r15/` bundle; do not copy them into Git.
Use the current clone-and-run instructions in
[`docs/task3_flow_equivalent.md`](../../../docs/task3_flow_equivalent.md).
The valid method is `r15-repro-v1`; `r15` is not a valid subcommand for the
current runner.
