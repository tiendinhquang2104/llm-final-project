# Level 2 D: frozen review protocol

Scope: one candidate D, only requested_level=2, versus unchanged zero-shot R15 A. No model API judge, training, public data inspection, public inference, push or leaderboard. Use label_space.json Level definitions above teacher examples. Qwen/Qwen2.5-Coder-7B-Instruct revision c03e6d358207e414f1eca0bb1891e29f1db0e242; identical tokenizer/NF4/seed/decoding/schema/attempt/token/time budgets/input fields. A and D first run with old R15 guard on exposed calibration. Only then may one separate guard be implemented and frozen before all confirmation outputs; rerun both A and D under it. Never revise prompt after calibration or confirmation.

Level2 defect feedback must connect an existing location/expression to a source/statement-grounded causal mechanism, with an optional valid-input consequence. Quoting existing source is allowed; supplying a replacement expression/value, imperative/recommendation to change code, ordered repair steps or solution code is forbidden. Describing a missing component differs from asking for it. Neither backticks nor 'thiếu'/'thay vì' alone is a rejection criterion. Source declarations and input assumptions override habitual repair advice.

Per ID and arm, review statement, entire code, valid-input domain, problem list and prerequisite policy, available compiler evidence, entire raw attempts and final feedback. Labels: location_correct, cause_correct, false_technical_claim, false_clean, semantic_repair, code_solution, generic, taxonomy_reasonable, unknown. Record reasons and source counterexample/basis; uncertain assessments are unknown, never human-verified. Both-correct requires a real defect, both location/cause, no material false claim or false-clean, not generic/unknown. Clean examples are scored separately as status_correct; do not award a cautious generic answer full diagnostic credit. Pure taxonomy emptiness is not by itself false-clean; feedback claiming a defective solution is correct is false-clean. Taxonomy is secondary and never a selection metric.

Measure raw semantic leak separately for initial attempt and all generated attempts, and final semantic leak separately from surface regex. Review all generated attempts; retry count is extra generations, fallback is the controller's recorded disclosure fallback, generic includes fallback/epistemic non-diagnoses. R15 fail-closed policy remains the explicit epistemic fallback retaining latest model labels after three rejected schema-valid attempts; no output for unresolved schema or infrastructure failure. Fallback is diagnostic failure and must not earn full marks. Guard never edits model prose.

Decision per guard on the confirmation set only: full ID/schema completion; zero final semantic repair/code/solution; strictly more source-correct location+cause diagnoses than paired A; no increase in false technical claims or false-clean; no increase in generic/fallback; all non-Level2 prompts byte-identical to R15. Unknown independence/material verdicts prevent promotion. Otherwise GIỮ R15. Small agent-authored train-derived samples provide limited offline evidence, no leaderboard prediction. The old 48 are exposed development only. Program execution and compilation require an available isolation sandbox; otherwise compiler status unavailable and static analysis only.
