# Operational taxonomy rulebook, grounded-v2

Only the ten strings in label_space.json are official. The distinctions below
are operational research choices, not boundaries confirmed by the instructor.
Examples are artificial development situations, never inference demonstrations.

| Official label | Minimum evidence and artificial example | Common confusion and insufficient evidence |
|---|---|---|
| Lỗi biên dịch | Actual source-bound C++ diagnostic, or explicit static syntax/type contradiction; undeclared identifier used in an expression | Warning, missing return at the end of int main, unavailable compiler, and runtime null dereference do not establish a compile error |
| Lỗi nhập/xuất | Input/output interface and source construct disagree; delimiter consumes the next record | Incorrect numeric result alone is not an I/O defect; fixed literal overriding filename parameter uses Hard-code |
| Lỗi logic | Concrete expression/branch/state transition contradicts a requirement under a valid condition | Avoid a generic extra Logic label for loops, indexing or algorithm defects |
| Lỗi vòng lặp | Bound, update or termination condition provably misses/repeats work or never progresses | A loop merely containing an arithmetic defect is not enough; one endpoint bug is not automatically also Edge case |
| Lỗi mảng/chuỗi | Index, capacity, length, storage or string operation fails under a valid input | A sufficiently large output array for n inputs is not an error; establish reachable invalid access |
| Lỗi hàm | Function contract, arguments, return value or required implementation missing | A defect in a helper is not automatically a function error; establish required/called function scope |
| Lỗi edge case | Specific boundary/special valid input omitted while the main mechanism applies elsewhere | Missing arbitrary general inputs is not an edge case; choose Loop for the same loop-bound cause |
| Lỗi thuật toán | Strategy or asymptotic work violates the mathematical requirement or input limits | Wrong output alone or an inefficient but adequate strategy does not establish it |
| Lỗi hard-code | Constant replaces a required variable input/parameter; return a fixed answer irrespective of input | A valid constant specified by the statement is fine; do not duplicate I/O for the same fixed-file cause |
| Lỗi style | Explicit method/style requirement is violated by an actual construct | Personal naming/formatting preferences, comments and unused helpers are insufficient |

One finding gets one primary category. Multiple labels require independent
findings with separate causes. Loop/Logic, Loop/Edge, Algorithm/Logic,
Function/Logic, Array/Edge and I/O/Hard-code do not overlap merely by consequence.
Two independent issues can share a source quote; the source reviewer must check
that they really are independent. This policy may disagree with original gold;
report that disagreement, preserve gold and score against both separately.

Every selected finding includes scope, exact source quote and derived span,
requirement reference, valid condition, observed behavior, causal conflict,
evidence type/reference, confidence and dispute status. Lexical matching verifies
provenance only. High-confidence model claims still need independent source
review to measure correctness. Medium/low/disputed hypotheses cannot support
exported labels. Invalid/uncertain is not an empty clean decision.

Compiler states are compiled/compile_error/timeout/unavailable/not_run; tests are
passed_cases/failed_cases/unavailable/not_run. Actual diagnostic/test references
must carry an ID; tests also require executed and trusted_expected with input,
expected and actual. No such new evidence is generated by this experiment.

The three diagnosis states distinguish confirmed_error,
plausible_but_unverified and no_error_found_with_available_evidence. A reasoned
empty set is a limited model assessment, not a proof of correctness. Blocked
prerequisite scope prevents a whole-program clean claim.

The feedback renderer receives only the Level view in C2. L1 contains status and
evidence limitation; L2 adds assessed scope and observed causal diagnoses; L3
adds repair direction; L4 adds source detail. A fallible Qwen semantic guard
screens support, main-error coverage, Level and Vietnamese. Its retry channel
contains fixed categorical codes, never free-text source/repair details.
Per-sentence finding citations are necessary traceability, not proof of entailment.
Exhausted retries remain unresolved and are never filled with placeholders.
